# EdgeLight-GAN — Scientific Reports Reproducibility Repository

**Manuscript:** EdgeLight-GAN: An Intelligent Lightweight Multi-Resolution Generative Adversarial Network for Real-Time Low-Light Image Enhancement

This repository provides the code organization, configuration, training/inference workflow, evaluation utilities, computational profiling, deployment benchmarking, and reproducibility documentation associated with the revised EdgeLight-GAN manuscript.

## Important provenance statement

This repository is a **manuscript-aligned reproducibility package** prepared from the revised manuscript specifications and available implementation-audit information. It must not be represented as the historical source tree that generated the manuscript's audited numerical results unless the authors have independently checked this repository against the original 43-file project.

The repository deliberately separates:

1. values reported in the manuscript; and
2. values freshly generated by executing the public code.

Fresh measurements must never be edited to force agreement with manuscript values.

## Experimental environment

- CPU: Intel Core i9-13900K, 3.0 GHz
- RAM: 64 GB DDR5
- GPU: NVIDIA RTX 4090, 24 GB
- OS: Ubuntu 22.04 LTS
- Python: 3.11
- PyTorch: 2.2
- CUDA: 12.1
- cuDNN: 8.9
- Input resolution: 256 × 256 pixels
- Random seed: 42
- Repeated experimental runs: 3
- Inference: trained generator only
- Discriminator: adversarial training only

## Installation

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Verify the environment:

```bash
python scripts/verify_environment.py
```

## Training

```bash
python train.py --config configs/config.yaml
```

The discriminator is used exclusively inside the adversarial training loop.

## Generator-only inference

```bash
python inference.py \
  --config configs/config.yaml \
  --checkpoint outputs/checkpoints/best_generator.pt \
  --input data/LOL/test/low \
  --output outputs/enhanced
```

The discriminator is not loaded or executed during inference.

## Evaluation

```bash
python evaluation/evaluate.py \
  --input outputs/enhanced \
  --reference data/LOL/test/high \
  --output outputs/results.csv
```

Supported metrics:

- PSNR
- SSIM
- LPIPS
- NIQE
- BRISQUE

Optional IQA dependencies are documented in `requirements.txt`.

## Parameter and FLOP verification

```bash
python scripts/verify_parameters.py
python evaluation/profile_model.py
```

The scripts report measurements from the current implementation. They do not hard-code the manuscript's reported parameter/FLOP values.

## Inference/FPS benchmarking

```bash
python deployment/benchmark.py \
  --config configs/config.yaml \
  --checkpoint outputs/checkpoints/best_generator.pt
```

The benchmark uses:

- generator-only execution;
- warm-up iterations;
- timed iterations;
- CUDA synchronization when applicable;
- mean latency;
- FPS calculated as `1000 / latency_ms`.

## Edge-device benchmarking

Run the relevant script on the physical device:

```bash
python deployment/benchmark_raspberry_pi5.py
python deployment/benchmark_jetson_xavier_nx.py
python deployment/benchmark_jetson_orin_nano.py
```

Power/energy values must be measured on the physical hardware using an appropriate measurement method. The scripts do not fabricate power values.

## Reproducibility

```bash
python scripts/reproducibility_report.py
```

The generated report records software, hardware, configuration, seed and model-count information.
